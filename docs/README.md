# Documentation

The protocol documentation for these contracts lives in [`protocol-docs/`](../protocol-docs/README.md)
in this repository. Start with [the system architecture](../protocol-docs/system/README.md); the
operational guides for [deploying an ecosystem](../protocol-docs/ecosystem-deployment.md) and
[upgrading an ecosystem](../protocol-docs/ecosystem-upgrade.md) sit next to it.

`ai-review/` holds the review guides and prompts used by AI-assisted code review.
