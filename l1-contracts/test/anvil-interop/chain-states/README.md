# Chain-state fixtures

Two kinds of directories live here, with OPPOSITE maintenance rules:

- **`v0.33.0` — FROZEN departing-version fixture.** The snapshot of the ecosystem the v34
  bootstrap edge departs from. It is the input of `run-v33-to-v34-upgrade-test.ts` and MUST NEVER
  be regenerated: contract changes on this branch must not touch it, exactly like the real chains
  it stands in for. (It was previously misnamed `v0.32.0` and kept getting regenerated from
  current sources, which silently destroyed its departing-version meaning.)

- **`v0.34.0` — current-source states.** Generated from THIS branch's sources by
  `setup-and-dump-state.ts` (the version name comes from `config/anvil-config.json`'s
  `stateVersion`), consumed by the interop tests and `run-v34-to-v35-upgrade-test.ts`, regenerated by the
  'Regenerate Anvil Interop Chain States' workflow whenever contracts change, and validated by
  the `state-generation-check` CI job.

When the NEXT protocol version starts (v35): freeze the then-current `v0.34.0` as its departing
fixture, bump `stateVersion` to `v0.35.0`, and regenerate.
